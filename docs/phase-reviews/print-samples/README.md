# Example paper review pack · 2026-10-01

These files use worked-example data, including a placeholder custom-change image. They
are for layout review with 生管, not customer or production use.

Print the PI, MI and specification PDFs on A4 at 100% size. Keep the sample
`custom-reference.png` with the MI/specification; its filename appears in their
attachment manifest. Compare the forms with the paper layout in
`reference/forms/real-forms-layout.md` and record any corrections to field placement,
Chinese terminology, legibility, signature areas, and attachment handling.

The technical proposal is included to show the three-part merge. Part A is explicitly
marked as a worked example and needs approved model literature before external use.

Phase 3 remains unaccepted until a printed PI and MI have been taken to 生管 and accepted.
